# Nekonata-team Tap

## How do I install these formulae?

`brew install nekonata-team/tap/<formula>`

Or `brew tap nekonata-team/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nekonata-team/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
